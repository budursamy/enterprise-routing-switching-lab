# Enterprise Routing & Switching Lab | Cisco Packet Tracer

## Project Overview
This project demonstrates the practical application of CCNA routing and switching concepts using Cisco Packet Tracer. The network topology simulates an enterprise environment with multiple routers and switches configured to enable communication between different network segments.

## Technologies & Concepts
- **IP Addressing and Subnetting:** Assigning IP addresses to network interfaces and network segments.
- **VLANs:** Segmenting the network into separate broadcast domains, if configured.
- **Trunking (IEEE 802.1Q):** Carrying traffic for multiple VLANs, if configured.
- **Inter-VLAN Routing:** Enabling communication between VLANs, if configured.
- **OSPF:** Dynamic routing between routers.
- **DHCP:** Automatic IP address assignment, if configured.
- **Network Connectivity Testing:** Verifying end-to-end communication using ping tests.

## Project Files
- `Enterprise-Routing-Switching-Lab.pkt` — The completed Cisco Packet Tracer project.
- `Screenshots/` — Screenshots of the network topology and connectivity tests.

## Testing & Verification
The network was tested in Cisco Packet Tracer using ping commands to verify connectivity between relevant network segments. OSPF was configured to enable dynamic route exchange between routers.
